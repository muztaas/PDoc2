A C# WinUI application using python for converting Word/Doc to PDF.
Uses the same coversion process applied by Adobe Reader for converting Word Doc to PDF, therefore, the file converted will be the same as done by Abode Reader.

Note: 
1. Microsoft Word should be installed for this application to work.
2. Only the Setup file **/tools/Output/PDoc2Setup.exe** will work without .NET & Python. The Setup file **/Output/PDoc2Setup.exe** needs .NET & Python installed in the system.
